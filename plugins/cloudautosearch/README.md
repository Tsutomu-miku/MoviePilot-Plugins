# 115 RSS 离线下载

RSS 自动下载和手动链接推送共用 115 登录、保存目录、去重记录及任务锁。

## 手动推送

1. 在插件配置中完成 115 登录并保存目标目录。
2. 打开插件详情页，在“手动推送”中粘贴磁力链接或可以直接下载的种子链接，每行一个，单批最多 20 条。
3. 点击“推送到 115”，查看每条链接的提交结果。提交在后台运行，关闭详情页后仍会继续；重新打开后点击“刷新进度”查看。

HTTP/HTTPS 链接必须返回 `.torrent` 内容，不是种子详情页或需要网页登录的页面。磁力链接支持十六进制、Base32 及 URL 编码的 BTIH。

手动推送不受 RSS 开关、关键词及大小过滤影响。默认跳过此前成功推送的资源；如果资源已经从 115 删除，可以勾选“重新提交已有成功记录的资源”。同一批内成功提交过的相同资源仍会跳过。

失败条目不会写入去重记录，可以再次粘贴重试。插件重载时尚未确认的条目会标为失败并提示先到 115 检查，避免误以为已经完成。页面中的“成功”表示 115 已接受离线任务，下载完成情况以 115 为准。

## 状态主页

- 显示保存的登录状态、RSS 开关、订阅数量、成功推送资源数及当前任务状态。
- 显示保存目录和定时周期，提供“刷新状态”和“立即运行 RSS”。登录凭据是否有效会在提交前校验。
- 展示最近 10 次 RSS / 手动推送记录及最新一批的逐条结果，使用中文状态。
- 页面生成只读本地数据，不访问 115；响应式布局沿用 MoviePilot 的主题和卡片。

## 安装及升级

插件版本为 **1.1.0**。请更新整个 `plugins/cloudautosearch` 目录，包含 `__init__.py` 和 `ui.py`，然后重新加载插件。仅替换 `__init__.py` 会缺少页面模块。

现有登录、RSS 配置、目标目录和去重记录继续使用。新增 `manual_job` 数据保存最新一批的进度，不保存原始下载链接、站点 passkey 或 115 Cookie 到运行记录。

## 验证

在仓库根目录运行：

```sh
python3 -m pytest plugins/cloudautosearch -q
```

测试使用模拟 115 响应，不创建真实离线任务。
